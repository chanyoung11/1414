## 전체 설명

```
주일마다 반복되는 일을 줄여 줍니다.

카톡으로 흩어진 악보, 매번 다시 적는 순서, 누가 무엇을 맡았는지 헷갈리는 편성.
1414은 찬양팀이 주일을 준비하는 과정을 한 곳에 모읍니다.

■ 콘티
곡 순서와 키, 송폼을 적고 악보를 붙이면 끝입니다.
인도자가 발행하면 팀원 앱에 자동으로 내려갑니다. 카톡에는 링크만 보내면 됩니다.

■ 악보
사진으로 찍은 악보를 올리면 단(段)을 자동으로 찾아 나눕니다.
A·B·C 구간을 표시하고, 형광펜·메모·가림막을 겹쳐 놓을 수 있습니다.
세션별로 다른 메모를 남기면 각자 자기 것만 봅니다.

■ 무대 모드
어두운 화면에 악보만 크게. 화면이 꺼지지 않습니다.
가로로 돌리면 두 단씩 자동으로 배치해 넘기는 횟수를 줄입니다.

■ 인쇄
반주자·싱어용으로 종이에 뽑을 수 있게 짜 줍니다.
곡이 중간에 잘리지 않도록 페이지를 맞춥니다.

■ 일정과 편성
다음 예배를 미리 만들어 두고 누가 어느 세션을 맡을지 정합니다.
정해지면 팀원에게 알림이 갑니다.

■ 라이브러리
한 번 올린 곡은 팀 라이브러리에 남습니다. 다음에 다시 쓸 때 그대로 불러옵니다.

■ 알림
콘티 발행, 편성 확정, 연습 안내를 알림으로 받습니다.
밤에는 알림을 받지 않도록 조용한 시간을 정할 수 있습니다.

인터넷이 끊겨도 이미 받은 콘티는 그대로 볼 수 있습니다.
```
