# 전역감사 — 2026-09-18

웹(`app/index.html` 6979줄) · 서버(`api/index.js` 2717줄 + `lib/` 12개) · 네이티브(안드 2·iOS 3)
전체를 정적 대조 + 실제 실행으로 훑었다. 아래는 **찾은 것과 고친 것**만 적는다.

## 고친 것

### 1. 안드로이드 앱에서 연습 녹음이 아예 안 됐다 (실사용 버그)
`getUserMedia({audio})` 를 쓰는데 `AndroidManifest.xml` 에 `RECORD_AUDIO` 가 없었다.
웹뷰는 매니페스트에 권한이 없으면 권한 대화상자도 띄우지 않고 바로 거절한다.
에뮬레이터에서 재현: `NotAllowedError / Permission denied`.
→ `RECORD_AUDIO` · `MODIFY_AUDIO_SETTINGS` 추가. 다시 확인: 권한 대화상자가 뜨고,
허용하면 `MediaRecorder` 가 `audio/mp4;codecs=opus` 로 녹음된다.
iOS 는 `NSMicrophoneUsageDescription` 이 있어 영향 없었다.

### 2. 아이콘 버튼 21개에 이름이 없었다 (접근성)
그림만 있는 버튼은 스크린리더가 "버튼"으로만 읽는다.
→ `title` + `aria-label` 추가(뒤로 · 닫기 · 메모 지우기 · 악보 지우기 · 5 빠르게 …).
화면에 보이는 모습은 그대로다.

### 3. 요금제 색이 라이트 모드에서 대비가 모자랐다
어제 넣은 Pro 파랑(#3E7BFA)·Pro Plus 보라(#8B5CF6)가 흰 배경에서 3.9:1 / 4.2:1 로
작은 굵은 글씨 기준(4.5:1)에 못 미쳤다.
→ 테마별로 나눴다. 라이트 #2C63D8(5.4:1) · #6B37CC(6.9:1), 다크 #6AA9FF(7.8:1) · #A78BFA(6.9:1).
금색 알약은 금 배경 대비 7.1:1 로 충분했다.

### 4. 죽은 CSS
`.stgpage .sgrid` — 무대 편집을 자유 배치로 바꾸면서 격자 렌더를 없앴는데 CSS 가 남아 있었다. 제거.

## 이상 없음을 확인한 것

- **서버 권한**: 라우트 114개 전수 대조. 로그인 확인이 빠진 비공개 라우트 **0건**.
  팀 자원 라우트는 모두 `requireMember` 를 거친다(`GET /ocr` · `GET /omr` 은 엔진 가용 여부만 주는 공개 정보).
- **SQL 인젝션**: 템플릿에 값이 들어가는 12곳 전부 코드 안 상수(테이블·컬럼 이름 리터럴, 정규식으로 검증한 날짜,
  `$n` 번호). 사용자 입력은 전부 파라미터 바인딩.
- **XSS**: 사용자 글자가 화면에 박히는 자리 97곳 점검. 위험한 자리는 모두 `esc()` 를 지난다.
  `toast()` 는 `textContent`, `confirm()` 은 HTML 이 아니다.
- **클라이언트 ↔ 서버 경로**: 클라이언트가 부르는 87개 경로 모두 서버에 있다.
  반대로 클라이언트가 안 부르는 8개는 크론·웹훅·공유 링크·이미지 직접 로드로 정상.
- **data-act ↔ 핸들러**: 146개 값 전부 핸들러가 있다(시트 안 `close` 는 시트 로컬 처리).
- **예외 처리**: `await api()` 는 한 곳만 호출부에 맡기고 나머지는 try/catch.
  `setInterval` 3개 모두 `clearInterval` 짝이 있다. 전역 `unhandledrejection` 핸들러 있음.
- **비밀값**: 레포에 키·인증서·서비스 계정 파일 없음(`.env.example` 만). 로그에 토큰·비밀번호 안 찍힘.
  응답에 `password_hash` 가 섞이는 곳 없음.
- **서비스워커**: `index.html` 은 네트워크 우선이라 배포가 바로 반영된다. `/api/` 는 캐시하지 않는다.
- **네이티브 설정**: 안드 권한 4개(인터넷·알림·녹음 2) · iOS 사용 설명 5개 · `UIBackgroundModes: audio` ·
  딥링크 파일 2개 모두 200.
- **실행 점검**: 화면 11개의 버튼 125개를 눌러 봤다 — 반응 없는 버튼 0개, 콘솔 오류 0건.
- **테스트**: 44개 전부 통과.
